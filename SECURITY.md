# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. You can also email security@flypennant.com.

Include the package and version (for example `@pennant/react@1.1.0` or `mcp/v1.0.0`), the steps to reproduce, and the impact you expect. Please give us a chance to fix it before you share it publicly.

## Supported versions

Security fixes go into the latest release of each package. Upgrade to the newest tag for that SDK to receive them.
